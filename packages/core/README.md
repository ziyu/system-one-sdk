# @system-one-ai/core

Core contracts and validated evaluation lifecycle. No concrete adapter or Fetch implementation is included.

```ts
import { createSystemOne } from '@system-one-ai/core';
// Supply an explicit adapter and transport to createSystemOne({ adapter, transport, apiKey }).
```

Requires Node.js 20+. This workspace is not yet published separately. Build from the repository with `npm run build --workspace @system-one-ai/core`.
